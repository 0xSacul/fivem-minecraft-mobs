No native YDR/YTD/YFT is required for this prototype. Original Minecraft textures
are loaded into a runtime TXD; the reconstructed model is drawn with textured triangles.
Invisible local CObjects provide entity anchors. Wings, tips, jaw, neck, tail and
legs use hierarchical procedural transforms. Weapon/vehicle hitboxes follow them.
A future rigged drawable can replace the renderer while retaining the gameplay modules.
